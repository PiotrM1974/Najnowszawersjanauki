# Małe kroki — nauka dla klasy 4

To jednorazowa, statyczna kopia aplikacji przygotowana do publikacji przez GitHub Pages. Zawiera bieżące materiały: 489 pytań w czterech przedmiotach (matematyka 237, język polski 137, angielski 66, przyroda 49), w tym 85 pytań do 17 rozdziałów „Opowieści z Narnii”. Powitanie brzmi „Witaj, uczniu!”.

## Publikacja

1. Utwórz repozytorium GitHub i prześlij **zawartość tego katalogu** bezpośrednio do jego katalogu głównego. Plik `index.html` musi znaleźć się w katalogu publikacji.
2. W repozytorium otwórz **Settings → Pages**.
3. Wybierz publikację z gałęzi, np. `main`, i folderu `/ (root)`, a następnie zapisz ustawienia.
4. Poczekaj na zakończenie publikacji. GitHub Pages udostępni aplikację pod adresem strony repozytorium.

Plik `.nojekyll` pozwala opublikować statyczne pliki bez przetwarzania przez Jekyll. Zgodnie z dokumentacją GitHub Pages można publikować pliki z katalogu głównego wybranej gałęzi: https://docs.github.com/en/pages/getting-started-with-github-pages/configuring-a-publishing-source-for-your-github-pages-site.

## Działanie i prywatność

- To statyczna strona: nie wymaga Node.js ani serwera aplikacji.
- Pytania i materiały są częścią tej kopii. Zdjęcia podręczników i lokalny plik z materiałami źródłowymi nie są dołączone.
- Postęp zapisuje się lokalnie w przeglądarce urządzenia i nie synchronizuje się z innymi urządzeniami.
- W kodzie i interfejsie nie ma kont, reklam ani analityki.
- Przy publikacji publicznego repozytorium jego kod i treści będą widoczne dla wszystkich.

## Jednorazowa kopia

Ten katalog jest migawką obecnej aplikacji. Nie synchronizuje się z główną kopią aplikacji, nie będzie automatycznie otrzymywał późniejszych pytań ze zdjęć podręczników i nie jest miejscem dalszej pracy nad aplikacją. Nowe materiały są nadal dodawane do głównej aplikacji; odświeżenie tej kopii publikacyjnej wykonam tylko na Twoją prośbę.
